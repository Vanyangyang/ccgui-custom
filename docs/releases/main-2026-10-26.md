# 2026-10-26 main 源码同步 / main source synchronization

本次更新自定义仓库的客户端和通用插件 SDK 源码，不发布新的安装包，不修改应用显示版本或既有 tag。

This update synchronizes client and general plugin SDK source in the custom repository. It does not publish an installer, change the displayed application version or move an existing tag.

## 内容 / Scope

- SDK 0.3.28：插件项目视图、独立窗口、原生任务协调、讨论及持续任务会话、图片附件、版本化固定指令、基于所属会话证据的受限记忆提炼，以及更新准备期间的插件服务关闭与退出确认。
- 客户端：跨工作区父子任务与会话归属、通信队列与成本审批、文件/图片展示、上下文与额度展示、引擎辅助进程和终端回收、检查点兼容与更新恢复。
- 保留通用接口的所有权、授权、取消、未知结果不重放和证据校验边界。

- SDK 0.3.28: plugin project views, detached windows, native coordination, discussion and continuous task conversations, image attachments, versioned fixed instructions, bounded extraction from owned conversation evidence, and plugin service shutdown and exit confirmation during update preparation.
- Client: cross-workspace task and session ownership, communication queues and cost approval, file/image presentation, context/quota presentation, engine helper and terminal cleanup, checkpoint compatibility and update recovery.
- Retain ownership, authorization, cancellation, unknown-outcome non-replay and evidence-validation boundaries in the shared interfaces.

## 排除内容 / Exclusions

不包含独立游戏工作台插件本体、业务界面、素材、项目数据或专用原生验收脚本。SDK 和客户端中的通用能力继续保留，测试使用虚构项目和会话，不发布本机运行数据、日志、会话历史或个人配置。

The independent game workbench plugin, business UI, assets, project data and dedicated native acceptance scripts are excluded. Shared SDK and client capabilities remain. Tests use synthetic projects and sessions; machine-local runtime data, logs, conversation history and personal configuration are not publication inputs.

## 二进制与升级 / Binaries and upgrades

当前源码使用 V3 持久化契约。V1/V2 不能通过热更新、混用 worker 或旧版回退进入 V3；升级须结束全部任务、退出全部实例及相关执行器，再使用对应源码构建并验证的完整安装包，保留原数据。原公开 `v1.1.1+protected.35` 安装包仍是 V2；后续具有相同显示版本的本地 V3 安装包也只对应各自构建时的源码，不等于此处最新 main。详见[原始发行记录](1.1.1+protected.35.md)与[升级契约](../runtime-live-update.zh-CN.md)。

Current source uses the V3 persistence contract. V1/V2 cannot enter V3 by hot update, mixed workers or rollback. Finish all tasks, exit every instance and related executor, then use a complete installer built and verified from the intended source while retaining existing data. The original public `v1.1.1+protected.35` installer remains V2. Later local V3 installers with the same displayed version correspond only to their own build-time source, not automatically to current main. See the [original release record](1.1.1+protected.35.md) and [upgrade contract](../runtime-live-update.zh-CN.md).
