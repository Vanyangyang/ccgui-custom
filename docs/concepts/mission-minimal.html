FIRST PRINCIPLES / MVP

只留下完成一件事的最短路径。

目标 → 流程 → 执行 → 决定 → 结果。
不是五个模块，而是同一页的五个状态。

  • 创作只需一句目标与四步流程，不要求用户学习节点配置。
  • 执行时保留可见的流程状态；子任务收在一步里，按需展开。
  • 需要反馈时，把决定、依据和操作直接带到用户面前，不另建通知中心。
  • 反馈只改变本次任务；再次确认后才完成，不静默修改长期 SOP。
  • 第一版不做流程库、定时任务、多人协作、自动发布与复杂权限设置。

演示边界：PR、反馈与通用目标映射到预设示例，任意输入不代表 AI 已理解。下方“演示下一步”模拟执行事件；没有定时器推进或真实后台任务。反馈内容会完整保留，但不会被模型解析。

项目边界：侧栏、会话列表与窗口页签为宿主外观示意，只有任务插件交互可用。现有 SDK 支持侧栏入口、中心页签和 Agent 轮次；紧邻“新建浏览器”的位置仍需调整宿主排序。本文件不是已安装插件。

真实产品启动前：必须补齐数据来源、处理范围与权限校验。本稿以明确的示例材料代替，不把输入一句话等同于已经取得数据授权。
